# 本地词频与可选个人词库同步

适用：0.1.1 open.1 开发版。以下描述实现设计；实际检查结果见 VERIFICATION.md。

## 经常用的字词优先

开启「按本机选词频率优先排序」后，只在选中候选时累计频次。常用短字词优先于未用或较少用的普通候选；频次相同保留引擎的原排序。全拼、简拼、双拼、五笔共用同一份本机字词频次，学习语言关闭时也可以累积。新功能从启用后的选词开始，不将过去的学习记录自动当成词频。

手动置顶和隐藏仍优先：隐藏项不显示，指定编码的置顶项排第一。日期、计算工具保持工具顺序，表情不参与学习排序。只记录最多16个Unicode码点、128个UTF-8字节的已选候选，排除分词组句、工具与表情；不会保存原始按键、未选择的输入码或长文稿。

词频文件是本机数据目录的 usage.tsv，计数至多1,000,000，最多2,000个字词，达到数量上限时淘汰最低频项。更新通过进程锁和原子替换，设置应用与输入组件共享。损坏记录不被选词操作覆盖；可主动清空恢复。关闭后停止读写和排序，现有记录保留，重新开启可继续；「清空本机词频记录」恢复默认顺序，不清空学习记录和手动候选偏好。

Mac设置主页的应用内选词与IMK候选均接入；Windows设置试用和TSF源码接入。真实系统上屏仍需分别验收，不能从引擎测试推断系统输入已可用。

## 可选同步

默认关闭。选择 iCloud Drive、群晖 Synology Drive 或其他同步文件夹，只是指定文件位置类型；需要用户先配置对应官方客户端，再选择其本机已有的同步文件夹。词伴开源版不登录Apple/NAS账号，不安装客户端，不更改NAS设置，不上传到词伴开源版服务器。

- [Apple：Windows中的iCloud Drive文件操作](https://support.apple.com/en-gb/guide/icloud-windows/-icwddbc813bd/icloud)
- [群晖：Synology Drive Client](https://kb.synology.com/zh-cn/DSM/help/SynologyDriveClient/synologydriveclient?version=7)

选择文件夹后仍需开启「启用个人词库同步」。同步自定义TSV词库和常用语（输入码与内容）；API密钥、服务配置、语音术语、录音、词频、学习记录、置顶/隐藏偏好都留在本机。文件为明文，请选私有文件夹；个人API密钥不在同步格式中。

启用时可立即同步；设置应用运行期间每60秒交换一次，Mac导入词库或保存常用语后也交换；Windows通过手动操作或定时交换。设置应用退出后没有后台服务继续运行。离线、文件夹不可用或校验失败会显示状态，离线输入仍可用。关闭后停止后续交换，已写入同步目录的副本保留，已由云客户端接收的文件不能撤回。

「文件夹交换完成」仅证明本机文件读写完成。iCloud/NAS远端上传、另一台设备下载、冲突副本以及按需下载的可用状态需要在官方同步客户端中确认；本轮仅使用临时文件夹模拟两台设备，没有真实云端/NAS往返测试。

## 合并和冲突

词库以内容SHA-256命名，交换时先核验完整性与内容，再导入本机的新文件，不覆盖原自定义词库。常用语按设备UUID保存版本1的JSON快照；仅本设备快照允许原子更新，不改其他设备快照。Mac与Windows使用同一格式。

同输入码、不同内容的常用语不自动覆盖，设置页显示冲突，可保留本机或采用另一版本。采用另一版本只替换该输入码；原有其他常用语保留。未处理的冲突不阻止离线输入。

删除是本机操作：移除词库时排除对应内容摘要，移除常用语时排除对应输入码，防止下一次同步把它重新导入；不删除其他设备或云目录的副本。Mac可用「恢复本机排除的同步内容」重新允许合并，Windows源码暂未提供此恢复按钮。关闭同步不会删除任何同步数据。

交换目录固定为所选文件夹内的 LexiIME-Open-Sync：

- dictionaries/<SHA-256>.tsv：自定义词库。
- phrases/<设备UUID>.json：本设备的常用语快照。

每份词库≤8MiB，共≤128份/64MiB；加载后仍受引擎50,000条总量限制。常用语每份≤1MiB/1,000条，最多128份设备快照。校验内容摘要、UTF-8、大小、字段、唯一输入码与合并总量，拒绝涉及路径中的符号链接或Windows重解析点。云目录中其他扩展名和临时文件不作为导入数据。
