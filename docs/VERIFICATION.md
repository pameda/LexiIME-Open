# 0.1.1 open.5 词库与候选下方译词（2026-10-12）

补齐288条原创常用词和6806条Unicode官方数据衍生的单字读音，内置有效记录合计7194条。`xiufu`的首选为“修复”，英语为repair; fix；没有译词的条目保留空列，不把单字读音或拼接结果冒充外语翻译。Unicode 18.0.0来源、固定下载摘要及完整Unicode License V3随词库打包，重复离线转换与两仓库字节一致性检查通过。此词库仍非成熟通用词频模型或全多音字数据库。

Mac候选横向排列，译词位于字词下方；短译词最多32个字素、单候选最多64个字素，单行宽度约束配合省略号，悬停仍可查看原文。按实际字体测量，超过96pt的词独占一页；其他候选按页面宽度与5/9个上限分页。所有候选保留，长词只减少当前页显示数；上下移动、数字选词、−/=和Page Up/Down使用同一组可见范围，提交时不截断原词。Windows TSF源码也同步下方译词、长度控制、长词单页及对应键路由，但未编译或在Windows运行。

两版均通过782项核心检查（普通构建与内存检查各一轮），13项自适应分页/译词检查，以及既有Mac契约、词频与同步隔离检查。核心长句检索的普通构建测得平均约0.62ms，此为本机约7000条记录的基准，不外推更大词库。安装包、预览ZIP及实际安装的版本、二进制、Info.plist、四份图标、每个数据文件和完整许可一致，ad-hoc签名通过。

开源版父组件仍enabled=false，实际系统切换未通过；同一候选布局实现已构建安装，但不能用私有版的截图和真实上屏结果替代开源版验收。保持开源输入源未启用，不启动第二个设置菜单图标。
