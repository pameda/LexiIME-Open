# 产品范围与路线

词伴开源版是独立实现的外语学习输入法项目，MIT许可，保留与现有项目并行发展的方向。支持英语、日语、西班牙语的词库释义，以及个人输入偏好和主动个人API。

## 已实现与待完善

| 能力 | 当前实现 | 下一步验收 |
|---|---|---|
| 系统输入 | Mac IMK、Windows TSF源码 | Mac启用/上屏修复、Windows编译和实机输入 |
| 输入方案 | 全拼、简拼、纠错、词典组句、演示双拼/五笔 | 成熟语言模型、完整码表、大词库 |
| 个人词库 | 事务校验TSV导入，演示词库100条 | 专业语言审校、合法来源与全量覆盖 |
| 个性化 | 选词频率；Mac候选置顶/隐藏/字号 | 跨应用候选行为与长期稳定性 |
| 常用语与工具 | 自定义触发码、模糊音、日期/时间/计算/符号/表情 | Windows与真实系统按键验收 |
| 同步 | 默认关闭，本机文件夹交换、自定义词库/常用语、冲突选择 | iCloud/Synology跨设备真实往返 |
| 语音 | Mac本地识别预览；Windows系统录音+个人API源码 | 真实权限、识别质量、确认上屏 |
| AI | Mac主动整理/翻译/润色/摘要/问AI，个人HTTPS API | 服务契约之外的真实质量与错误处理 |

## 开发优先级

1. 修复并证明系统输入源启用、选择与跨应用上屏；完成Windows编译及TSF门槛。
2. 验证真实语音、个人API、跨设备同步以及安装/卸载/回退。
3. 核验可再分发词库/模型来源与许可，补充完整双拼/五笔、语言审校和大词库性能。
4. 完成正式签名、公证与干净系统下载安装验收。

公开源码不代表所有功能已经成熟。青简、微信输入法、Typeless和Chatterfly只作功能参考，具体来源见THIRD_PARTY_NOTICES.md与FEATURE-REFERENCES.md。现阶段未复用GPL代码、商业词库或参考产品媒体。
