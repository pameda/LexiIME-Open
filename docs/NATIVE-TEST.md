# Mac原生输入验收

自动脚本只使用新建的“词伴开源版 · 专用自动测试文档”，仅在其保持前台时经系统键盘路径输入固定测试字符，并设置事件目标PID。不读取私人文档、不录音、不调用个人API。执行前需获得测试人员对安装、输入源变更及原生辅助功能/按键自动化的明确授权。

```sh
bash script/build_system_test.sh
python3 script/run_system_test.py
```

需要解锁的图形会话与已有权限。脚本不会尝试解锁、修改系统保护、注销或重启输入服务；会临时阻止空闲休眠，结束后恢复。

## 成功条件

1. 保存原输入源与设置字节；测试中关闭云端、学习记录、词频和文件夹同步。
2. 独立测试窗口获得前台，在ABC下输入nihao并准确读回，以校准按键送达。
3. 注册并选择开源版，实际读回 local.inputmethod.lexiime.open 才继续。注册返回0不足以通过。
4. 校准成功后检查12项中文输入交互，以及组字、焦点切换、固定测试密码框。丢失焦点或遇到锁屏立即停止。
5. finally恢复原输入源及原配置，关闭测试窗口。有自定义词库时停止，避免纳入私人词条。

输出仅在本机build/system-test。退出0要求用例和回退全部通过；锁屏、输入源未选中与任何失败均返回非0。源码包不包含这些状态文件。当前开源版已执行真实注册与状态检查，但启用未通过，因此未触发本版本的中文按键用例。

## 设置页只读检查

在设置应用运行时使用 script/check_settings_ui.py 的 welcome、input、tools、voice、sync 参数。用 --input / --tools / --voice / --sync 正常启动应用可打开对应页面。检查器仅读取本应用可访问性树，不点击、发键、录音或上传。
