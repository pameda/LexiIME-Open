# 桌面输入与语音表达参考（2026-10-10）

词伴开源版保持独立实现，只参考公开产品行为；没有复用参考产品的代码、词库、模型或品牌资产，也没有安装其软件或 SDK。

参考来源为 [微信输入法官网](https://z.weixin.qq.com/)、[Typeless 官网](https://www.typeless.com/)与 [Ask anything](https://www.typeless.com/ask-anything)、[腾讯 Chatterfly](https://chatterfly.tencent.com/)。微信页面内的桌面更新记录已按 macOS/Windows 分类核对；不将移动端独有能力当作桌面功能。

微信桌面记录涵盖常用语、自定义触发码、模糊音、候选管理、日期/时间/计算、表情、AI 与语音等方向。Typeless 强调整理口语、处理重复和自我修正、个人术语、语气与翻译；Chatterfly 强调语音与键盘表达、意图和场景理解。以下为词伴开源版的实际实现状态，不是参考产品完整功能列表。

## 使用

Mac设置→「快捷工具」可管理常用语、恢复候选偏好、试用本地工具。例如添加 `mail` 与一个邮箱，主页试用输入 `mail` 即可选择；文本不会自动复制或发出。常用语不附造出来的译词，也不计入演示词库条数。

工具例子：`v500+21` → `521`；`v(2+3)*4` → `20`。仅支持加减乘除、括号、小数与正负号，拒绝除零、非法表达式、非有限值或绝对值超过10¹²的中间/最终结果。没有执行脚本或调用系统命令的路径。日期时间按本机时区生成。中文系统输入中，算式数字/运算符先作为表达式输入，空格或Enter/等号接受结果；其他编码的Enter保持输出原编码。

Mac设置→「语音输入」可填写个人术语。识别仍只使用Apple本地资源，最多60秒；文字预览下方提供可选AI处理。配置个人HTTPS Chat Completions API并开启主动发送后，点击明确的发送按钮才上传这段文字及术语。候选译词上限仍为128字，文稿处理上限4000字。AI结果可能改变事实，请对照保留的原文检查；这一步尚未真实联网测试。

润色可选自然、正式、友好语气；翻译目标为英语、日语、西班牙语；摘要只提出文本中已有的信息。问AI不访问本机文件、网页搜索、邮箱或日历，也不会执行任务。切换文稿/动作/目标语言、离开界面或取消会作废未完成结果；每次发送都是独立请求，没有隐式对话历史。

Apple术语接口依据 [contextualStrings 官方文档](https://developer.apple.com/documentation/speech/sfspeechrecognitionrequest/contextualstrings)。词伴开源版将词数限制为100，单词最多40字符；提示不保证识别成功。个人API服务商的日志、保留和训练规则由服务商决定，词伴开源版不冒充参考产品的云隐私承诺。

## 仍待完善

- 系统输入源可用性与跨应用上屏、真实麦克风和AI质量、Windows构建/安装均是独立门槛。
- Fn长按/全局自定义快捷键、上下文自动识别、选中文本语音编辑、连续不限时转写、混合语言自动检测尚未实现。
- 跨设备剪贴板/传文件、账号同步、完整双拼/五笔与大词库、在线表情包、自动学习写作风格尚未实现。
- 当前采用用户选择动作与语气；没有声称已经具备Chatterfly式自动执行任务或Typeless式全应用语音编辑。
